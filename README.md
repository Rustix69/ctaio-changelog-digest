# Claude Code Changelog Digest

A small static page that pulls the official Claude Code changelog and turns it into a readable digest for people using it in real workflows. Each release is tagged by what it actually touches (hooks, permissions, MCP, CLI flags, IDE integration), so you can scan for changes that affect your setup instead of reading every line. It's built as a Python script plus GitHub Pages, with no backend, and every entry links back to the source so you can verify it yourself. Made as a quick build for [ctaio.dev](https://ctaio.dev).

Live: https://rustix69.github.io/ctaio-changelog-digest/
